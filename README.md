# カツドンチャンネル

非公式ファンアーカイブ。3Dギャラリー、名言コメント、VOICEVOX:ずんだもんの読み上げ。

公開ページ: https://shortinmsleeper.github.io/katsudon-channel-test/

- 下のサムネイルか写真をタップして巡る
- 「名言」からフレーズを流せる
- 同じ写真を続けて3回タップすると、いつものあれが流れます
- ミニゲーム「配信我慢」: https://shortinmsleeper.github.io/katsudon-channel-test/game.html
  - 便意を我慢して配信を終える
  - カツドンの内心はずんだもんが読み上げ
  - 長押ししすぎると逆噴射
  - 難易度 EASY / HARD / EXTREME
